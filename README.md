# 💰 MapPenny

### Personal Finance Management Website

MapPenny is a responsive personal finance management website designed to help users understand and manage their money more effectively.

The website allows users to calculate their monthly expenses, check their remaining balance, set savings goals, track savings progress, and learn simple financial management tips.

---

## 🌐 Project Overview

Managing personal finances can be difficult without a clear understanding of income, expenses, and savings.

MapPenny provides simple tools that help users:

- 💵 Track monthly income
- 💳 Calculate and manage expenses
- 🎯 Set savings goals
- 📊 Check savings progress
- 💡 Learn financial management tips
- 🌙 Switch between Light Mode and Dark Mode
- 📱 Use the website on mobile, tablet, and desktop devices

---

## ✨ Features

### 💵 Income & Expense Calculator

Users can enter their monthly income and different expenses such as:

- Rent
- Food
- Transport
- Education
- Other expenses

The website automatically calculates:

**Total Expenses**

and

**Remaining Balance**

---

### 🎯 Savings Goal

Users can create a savings goal by entering:

- Goal name
- Target amount
- Amount already saved

MapPenny calculates:

- Target amount
- Amount saved
- Remaining amount
- Savings percentage
- Progress bar

---

### 💡 Smart Financial Tips

MapPenny provides simple financial tips including:

- Follow the 50/30/20 rule
- Track every expense
- Set financial goals
- Build an emergency fund
- Use credit wisely
- Invest for the future

---

### 🌙 Dark & Light Mode

Users can switch between:

- ☀️ Light Mode
- 🌙 Dark Mode

The selected theme is saved using browser `localStorage`, so the preference remains after refreshing the page.

---

### 📱 Responsive Design

The website is designed to work on:

- 📱 Mobile phones
- 💻 Laptops
- 🖥️ Desktop computers
- 📟 Tablets

It also includes a responsive hamburger navigation menu for smaller screens.
